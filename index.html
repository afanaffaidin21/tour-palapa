Dari Gunung ke Lautan

Kabut Bromo, api biru Ijen, tirai Tumpak Sewu, teluk Papuma, dan laguna Sempu. Mulai dari kabut, tutup di laguna.

Pilih Tempo Liburanmu

Tiga tempo pilihan: satu malam untuk Bromo, dua untuk Ijen dan Tumpak Sewu. Semuanya sudah termasuk transport, tiket, dan guide lokal.

1D1N Pemula

Paket Bromo Sunrise

Probolinggo, Jawa Timur

Berangkat tengah malam dari Surabaya atau Malang, lalu menikmati matahari terbit dari Penanjakan sebelum turun ke kawah berasap.

  • Transport AC + 1 malam lodge
  • Jeep 4WD ke Penanjakan & lautan pasir
  • Tiket masuk kawasan Bromo
  • Guide lokal + makan ringan

mulai dari

Paket Api Biru Ijen

Banyuwangi, Jawa Timur

Trek tengah malam ±2 jam menuju puncak kawah untuk api biru, dilanjutkan ke tepi danau asam terbesar di dunia.

  • Transport AC + 1 malam guesthouse
  • Ojek trek puncak + masker asam
  • Tiket masuk kawasan Ijen
  • Guide berlisensi + sarapan

mulai dari
Rp 1.250.000 / pribadi

Paket Tumpak Sewu

Lumajang, Jawa Timur

Panorama air terjun dari kaki gunung, lalu turun lewat tangga besi ke dasar kolam untuk dua sudut terbaik.

  • Transport AC + 1 malam homestay
  • Panorama bukit + trek dasar kolam
  • Tiket masuk + helm & guide lokal
  • Sarapan + air mineral

mulai dari
Rp 1.450.000 / pribadi
