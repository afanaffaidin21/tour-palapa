# Tour Palapa

Website wisata Jawa Timur dengan HTML, Tailwind CSS melalui CDN, dan JavaScript vanilla.

Website: https://afanaffaidin21.github.io/tour-palapa/

## Mengubah website

Edit `index.html`, lalu jalankan dari folder project:

```bash
git add index.html
git commit -m "Update website"
git push origin main
```

GitHub Pages otomatis menerbitkan perubahan dari branch `main`, folder root. Tunggu deployment selesai di tab Actions; alamat website tetap sama.

## Preview lokal

Buka `index.html` di browser dengan koneksi internet untuk memuat Tailwind CSS, font, dan gambar.

File `.nojekyll` membuat GitHub Pages menyajikan file statis tanpa pemrosesan Jekyll.
